# Claritas Viz semantic-topology boundary

Tracking: DEN-1949; Claritas umbrella DEN-617.

Embedded Alerts uses `claritas-viz` to lay out an application-supplied semantic topology. Claritas is presentation only: it does not infer semantic edges, classify alerts, mutate embeddings, or authorize access.

TypeSpec and Draft 2020-12 JSON Schema are independently authored peer authorities. TJSV emits comparison-only TypeSpec witness schema, verifies recorded expectations, and fails closed on drift.
